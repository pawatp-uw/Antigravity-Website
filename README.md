# My Blog

A clean, minimalist blog website with an editorial layout.

## Features
- **Clean white canvas**: Refined typography with high contrast and readability.
- **Top navigation bar**: Black header featuring links to `field notes`, `home`, `about`, `contact`, and `journal`.
- **Top-down journey stream**: A chronological sequence of 5 journal entries under the title **My Blog**.
- **Left-aligned imagery**: Custom vector illustrations with a 1–2 sentence narrative description on the right.
- **Responsive design**: Seamlessly adapts to desktop, tablet, and mobile screens.

## File Structure
- `index.html` — The primary HTML5 structure and semantic markup.
- `styles.css` — Modern styling, responsive flexbox layout, and typography rules.
- `images/` — Five custom SVG illustrations:
  - `journal-1.svg` (Departure at Dawn)
  - `journal-2.svg` (Canopy of the High Pines)
  - `journal-3.svg` (Ink & Field Notes)
  - `journal-4.svg` (Edge of the Headlands)
  - `journal-5.svg` (Campfire Embers & Starlight)

## How to View
Double-click `index.html` in your file explorer, open it directly in any web browser, or serve it using Python's built-in HTTP server:
```bash
cd "/Users/palmpunnaket/Antigravity website practice"
python3 -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
